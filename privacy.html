Kebijakan Privasi — Gaji Host Live

Terakhir diperbarui: 11 November 2026 · Pengembang: Riska Puspita, S.Pd. (riska.dyra21@gmail.com)

Aplikasi Gaji Host Live adalah aplikasi web untuk menghitung gaji host live TikTok (gaji pokok, uang makan, dan bonus omset). Kebijakan ini menjelaskan data apa yang diakses aplikasi dan bagaimana data tersebut digunakan.

1. Data yang diakses

Untuk masuk ke aplikasi, pengguna login dengan akun Google. Aplikasi menerima informasi dasar akun Google pengguna (nama, alamat email, dan foto profil) hanya untuk keperluan login dan menampilkan identitas pengguna di dalam aplikasi.

Data gaji yang pengguna masukkan (daftar host dan tarif per jam, akun TikTok, tanggal, durasi, dan omset sesi live) disimpan di dalam sebuah spreadsheet bernama "Gaji Host Live" yang dibuat otomatis di Google Drive milik pengguna sendiri.

2. Izin Google yang digunakan

Aplikasi meminta dua izin Google berikut, dan hanya menggunakannya untuk keperluan di bawah ini:

  • Melihat, mengedit, dan membuat spreadsheet (spreadsheets) — untuk membuat dan membaca spreadsheet "Gaji Host Live" milik pengguna, serta menyimpan perubahan data gaji ke spreadsheet tersebut.
  • Melihat dan membuat file di Google Drive (drive.file) — untuk mencari dan membuat spreadsheet "Gaji Host Live" di Drive pengguna.

3. Bagaimana data digunakan

Data hanya digunakan untuk menjalankan fungsi aplikasi: menghitung gaji, menampilkan kalender dan rekap, serta mengunduh rekap dalam bentuk Excel dan PDF. Data pengguna tidak dibagikan, tidak dijual, dan tidak dikirim ke pihak ketiga mana pun. Data tersimpan di Google Drive milik pengguna sendiri, bukan di server pengembang. Aplikasi ini tidak menampilkan iklan dan tidak menggunakan pelacak analitik pihak ketiga.

4. Penyimpanan dan penghapusan data

Data tersimpan selama pengguna memakai aplikasi. Pengguna dapat menghapus data gaji kapan saja dari dalam aplikasi (tombol Hapus) atau dengan menghapus spreadsheet "Gaji Host Live" dari Google Drive-nya. Pengguna juga dapat mencabut akses aplikasi kapan saja melalui pengaturan Akun Google (Keamanan → Akses pihak ketiga). Setelah akses dicabut, aplikasi tidak dapat lagi membaca atau menulis spreadsheet pengguna.

5. Keamanan

Akses ke data dilakukan melalui login Google pengguna dan izin OAuth Google. Pengembang tidak pernah melihat, menyimpan, atau meminta sandi Google pengguna.

6. Perubahan kebijakan

Jika kebijakan ini berubah, tanggal pembaruan di atas akan diperbarui.
